# Portfolio — RASOLOHERY Sitraka Evariste

Portfolio professionnel développé avec **React 19.3.1**, **TypeScript 5.8**, **Vite 8** et **Tailwind CSS 4**.

## Lancement en local

1. Installer **Node.js** (version 20.19+ ou 22.12+ recommandée).
2. Ouvrir un terminal dans ce dossier et installer les dépendances :
   ```bash
   npm install
   ```
3. Démarrer le serveur de développement :
   ```bash
   npm run dev
   ```
4. Ouvrir `http://localhost:5173` dans votre navigateur.
